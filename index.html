Google Maps folder

Every pin opens in Google Maps. To get them all as one folder, with a layer for each city:
  1. Copy the map file below (or use the asia-quest.kml file from the chat).
  2. Open Google My Maps and press Create a new map.
  3. Press Import and upload the file. Each city becomes its own layer.
  4. In the Google Maps app the map appears under Saved → Maps.
